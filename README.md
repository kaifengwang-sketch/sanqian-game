# 三千块进城

一个文字养成小游戏。汉语言文学毕业生揣着 3000 块来到南屿，找住处、面试、上班、跳槽，五年后在同学会上揭晓结局。

手机和电脑的浏览器都能玩，存档保存在当前浏览器里。

## 玩法

- 找工作时一回合是一周：投简历、刷题、打零工，下周去面试。面试官有好有坏，专业题答得好不好、期望薪资报多少，决定拿到什么 offer，还是“回去等通知”。
- 上班后第一年一回合是一个月，转正后从第二年起一回合是一个季度：认真干活、加班、摸鱼、学习、搞关系、偷偷看机会。每年 1 月和 7 月考核。
- 摸鱼被抓、试用期没过、连续两次绩效 C 都会被辞退；钱花光又没工作，就只能回家。
- 一共 7 个结局，从“回家啃老”到“年入百万打工人”。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html` | 游戏本体，由 `build.sh` 生成 |
| `src/a_head.html` `src/b_body.html` | 样式和页面结构 |
| `src/c1_base.js` | 工具函数、岗位、住处 |
| `src/c2_interview.js` | 面试题和面试流程 |
| `src/c3_events.js` | 随机事件 |
| `src/c4_scenes.js` | 场景和结局 |
| `src/c5_engine.js` | 行动、回合结算、对外接口 |
| `src/d_ui.js` | 界面 |
| `src/e_art.js` | 插图：用 canvas 画的南屿夜景，近一年挣得越多，亮灯的窗户越多 |
| `src/sim.mjs` | 用机器人批量试玩，看各结局的比例 |

改完 `src/` 以后运行 `./build.sh` 重新生成 `index.html`。调平衡：

```sh
./build.sh && node src/sim.mjs src/core.js 2000
```
